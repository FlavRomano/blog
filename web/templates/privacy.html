Privacy

This site collects as little personal data as possible.

  • Analytics: Cloudflare Web Analytics, which is cookieless and does not track individuals across sites.
  • Comments: only a display name and the comment text are stored. No email address is collected.
  • IP addresses: never stored in clear. A salted one-way hash is kept to rate-limit and block abuse.
  • Bot protection: Cloudflare Turnstile is used on the comment form.
  • Cookies: none for visitors. A session cookie is used only for the site owner's admin login.
